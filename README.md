# Irina Kareva home page

This repository publishes the neutral landing page at `irinakareva.com`.

Destinations:

- Science and consulting: `https://www.quercusinsights.com/`
- Music: `https://music.irinakareva.com/`

Compatibility pages:

- `/music/` redirects old music links to the music subdomain.
- `/cv/` redirects old CV links to Quercus Insights.
- `404.html` helps visitors who follow any other outdated address.

Do not add a `CNAME` file until the preview site has been checked and the music site is working at `music.irinakareva.com`. Setting the custom domain in GitHub Pages will create or update that file.
